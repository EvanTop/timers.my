## ✨ 功能特性

- 📅 **倒计时 & 正计时** — 记录将要发生的事件，也记录已经走过的日子
- 🏷️ **分类标签** — 工作、旅行、健康、生活，一目了然
- 💾 **本地持久化** — 数据存储在浏览器 LocalStorage，无需注册，隐私安全
- 📱 **响应式布局** — 完美适配桌面端与移动端
- ⚡ **轻量极速** — 纯前端实现，零依赖，秒开即用

## 🎯 设计理念

> **"Time is a system. Make it yours."**

Timers.my 相信时间是一种可以被感知、被管理的系统。通过将抽象的时间转化为具体的数字，让每一天都充满意义。
